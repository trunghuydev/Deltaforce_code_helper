# Delta Force Code Helper

Tool tự động đổi giftcode cho game Delta Force




---

## Cài đặt

**1. Tải code về**

Bấm nút **Code** màu xanh ở góc phải phía trên trang GitHub này → chọn **Download ZIP** → giải nén ra → để thư mục đó ở chỗ nào dễ tìm.

**2. Mở trang quản lý tiện ích của Chrome**

Gõ `chrome://extensions/` vào thanh địa chỉ rồi Enter. Bật cái công tắc **Chế độ dành cho nhà phát triển** ở góc trên bên phải.

**3. Load vào Chrome**

Bấm **Tải tiện ích đã giải nén** → chọn thư mục bạn vừa giải nén → xong.

Sau đó bấm vào biểu tượng  🧩 góc trên bên phải Chrome
---

## Cách dùng

1. Vào trang đổi code Delta Force, đăng nhập tài khoản trước
2. Bấm vào biểu tượng tool trên Chrome
3. Dán danh sách code vào ô trống, mỗi code một dòng
4. Bấm **Bắt đầu**, ngồi chờ
5. Xem kết quả bên dưới

Thời gian chờ giữa mỗi code mặc định là 5 giây. Nếu bị báo lỗi thao tác quá nhanh thì tăng lên 8-10 giây.

## Lưu ý

Nếu bạn bấm ra ngoài khung tool trong lúc nó đang chạy thì không sao, nó vẫn chạy ngầm. Bấm vào lại sẽ thấy tiến trình vẫn đang chạy bình thường.

Nếu muốn dừng thì bấm nút **Dừng**.
